# Gather 0.10.0-dev.9 — Windows preview

Gather is a Windows messaging hub with separate service accounts and side-by-side conversations. This is a development prerelease for Windows 11 x64.

## Download and install

Download **Gather-Setup-0.10.0-dev.9.exe** from this release's Assets. Quit any running Gather through **Settings > Quit Gather**, then run setup. Existing profiles and settings are retained.

See the [Windows installation guide](https://github.com/Housekeeping93/gather/blob/main/docs/INSTALLATION.md) for requirements, connecting services, updates and troubleshooting. Microsoft Edge WebView2 Runtime is required; Gather's .NET and Signal/Java dependencies are bundled. The installer is unsigned.

## What's new

- **Compact / Comfortable layouts:** choose shell spacing in Settings without changing provider zoom.
- **Layout focus view:** Ctrl+Shift+F hides the sidebar and pane headers. Exit focus view restores them; the preference survives restart.
- **Quick switch:** Ctrl+K searches account/provider names, with recently used accounts first. Existing visible accounts keep their session and pane.
- **Narrow-window actions:** secondary commands remain available under More actions. Existing focus timers and scheduled Do Not Disturb are preserved.

## Checks and limitations

The Release build is clean. 83 automated checks pass; two existing registry-write checks were explicitly skipped. Published and QA-installed copies pass runtime/logo inventory and isolated startup checks. Native layout checks pass at 125% display scale in both presets and focus view.

Physical shortcuts from authenticated provider pages, other display-scale transitions, caption interactions and Narrator still need desktop verification. Signal is a text-focused development preview; attachments, calls and older phone-message import are not implemented. Messenger and Discord integrations are experimental. There is no automatic updater.
