# Gather 0.10.0 - MVP

Gather's first full MVP release for Windows 11 x64. This release includes the privacy curtain and window-size fix from dev.11, along with the earlier quick switch, layout presets and Focus / Do Not Disturb features.

## Install or update

Download **Gather-Setup-0.10.0.exe** from Assets below. Quit the running Gather instance through **Settings > Quit Gather** or its tray menu, then run setup. Existing account profiles and settings are retained. The installer bundles .NET and the Signal/Java runtime; Microsoft Edge WebView2 is required. The installer is unsigned.

See the [installation guide](https://github.com/Housekeeping93/gather/blob/main/docs/INSTALLATION.md).

## Included in the MVP

- Separate accounts for WhatsApp, Telegram, Slack, Messenger and Discord, plus native Signal text conversations.
- Single or split view with a resizable divider, pane swapping and saved layout. **Alt+F** toggles split view and keeps the focused conversation when collapsing.
- **Ctrl+K** quick switch searches account/provider names and remembers recent accounts.
- Compact / Comfortable spacing and **Ctrl+Shift+F** layout focus view.
- **Ctrl+Shift+P** privacy curtain hides conversations, account details and Gather popups and suppresses notifications. Settings offers alternative shortcuts. Covering and restoring preserve window size and maximized state.
- Timed focus, recurring quiet hours, per-account exceptions, notification preview preferences, unread indicators and tray operation.
- Light/dark/system appearance, service zoom and optional Windows startup.

## Scope and known limits

Signal remains a text-focused integration: attachments, calls and importing older phone history are not included. Messenger and Discord support is experimental. Web services can change their sign-in requirements. Gather has no automatic updater. The privacy curtain is a screen privacy feature that anyone can restore; it does not authenticate the user.

The automated suite passes 87 checks; two registry-write checks are skipped in the build environment. Published and QA-installed packages are checked for bundled runtime integrity and empty/normal startup. Native privacy checks cover notifications, dialogs, popup visibility, retained sessions and exact window geometry at custom and maximized sizes. Physical shortcut input, Narrator, authenticated browser continuity and other display scales still require desktop verification; the offline WebView2 diagnostic could not initialize a browser controller in the build session. See [verification details](../G18-verification.md).
