# Gather 0.10.0-dev.10 - privacy curtain and split shortcut

- **Privacy curtain:** Ctrl+Shift+P hides conversations, account details and registered Gather popups. Restore with the same shortcut or Show conversations. Change the shortcut in Settings to Ctrl+Shift+L or Ctrl+Shift+H. Available in both normal and focus view.
