# Gather 0.10.0-dev.11 - preserve window size in curtain mode

Activating or dismissing the privacy curtain preserves the current window size, position and maximized state. Returning focus from a covered Gather popup also preserves the main window's geometry.

The window activation helper now uses Windows' show command for windows that are already open, and restores only minimized windows. Previously it always requested restore, which unmaximized Gather when the curtain appeared.

The privacy diagnostic asserts exact window bounds, presenter state and saved size before and after covering, popup activation while covered, and uncovering at two custom window sizes and maximized size. It also retains the existing privacy, notification-routing, dialog and session checks.

Install `Gather-Setup-0.10.0-dev.11.exe` after quitting the running Gather instance through Settings or the tray menu. Earlier installers are retained.
